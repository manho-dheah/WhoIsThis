# منهو ذية — V2.2 Visual Upgrade

نسخة تجميلية كاملة للموقع مبنية فوق V2.1 بدون تغيير قاعدة البيانات أو حذف أي بيانات.

## ما تغير في V2.2

- تغيير هوية الموقع إلى **منهو ذية**.
- استخدام ألوان مستخرجة بصريًا من الشعار: البنفسجي/النيلي، الذهبي، البيج، البني والأحمر الطوبي.
- عرض صورة الشعار كاملة في جميع المواضع باستخدام `object-fit: contain` بدون قص.
- Header ثابت جديد وهوية أوضح.
- Hero جديد بعنوان «مين أخذت معه؟ 👀».
- إحصاءات تلقائية لعدد أعضاء هيئة التدريس وعدد التجارب.
- بحث بارز مع فلاتر وأزرار أقسام سريعة.
- بطاقات أعضاء هيئة تدريس محسنة، مع إبراز «اقرأ التجارب» بدل «قيّم».
- ألوان هادئة لمستويات التقييم.
- صفحة/نافذة الدكتور أصبحت Profile أوضح مع ملخص إحصائي وتجارب الطلاب.
- نموذج التقييم أصبح يعتمد على نجوم كبيرة وتفاعلية.
- تحسين كامل للجوال والآيباد والكمبيوتر.
- تحديث تصميم لوحة الإدارة بنفس الهوية.
- Footer وتوضيح أن المنصة طلابية مستقلة وغير رسمية.

## النشر

لا توجد أي Migration جديدة لهذه النسخة.

1. فك ضغط `WhoIsThis-V2.2.zip`.
2. ارفع **محتويات المجلد** إلى جذر مستودع GitHub الحالي واستبدل الملفات المتطابقة.
3. اعمل Commit إلى `main`.
4. Netlify سيعمل Deploy تلقائيًا.

بيانات Supabase الحالية (الدكاترة والتقييمات والبلاغات) لا تتأثر بهذا التحديث.
